# Online Book Store SQL Analysis Project

## Project Overview
This project focuses on analyzing an Online Book Store database using PostgreSQL. The objective is to explore book inventory, customer information, and order transactions to answer important business questions and derive meaningful insights using SQL.

## Database Design
The database consists of three relational tables:

- **Books:** Contains book details, authors, genres, publication years, prices, and available stock.
- **Customers:** Stores customer information, including names, email addresses, phone numbers, cities, and countries.
- **Orders:** Contains order transactions, customer IDs, book IDs, order dates, quantities, and total amounts.

Primary Keys and Foreign Keys are used to establish relationships between the tables.

## Business Analysis & Key Questions

### Basic Analysis
- Retrieve books based on genre and publication year.
- Identify customers from specific countries.
- Analyze orders within a specific date range.
- Calculate total book inventory and revenue.
- Identify the most expensive book and lowest-stock book.
- Find orders based on quantity and transaction amount.

### Advanced Analysis
- Calculate total books sold by genre and author.
- Find the average price of Fantasy books.
- Identify customers who placed at least two orders.
- Find the most frequently ordered book.
- Identify the top three most expensive Fantasy books.
- Analyze customer spending patterns.
- Calculate remaining book stock after fulfilling orders.

## Project Objectives
- Understand relational database structures.
- Practice SQL queries on a real-world business scenario.
- Analyze sales, inventory, and customer purchasing behaviour.
- Extract business insights using SQL joins and aggregate functions.
